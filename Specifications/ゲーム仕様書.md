# ゲーム仕様書

## 第1章:ゲーム概要

- **タイトルコンセプト**: 自分だけの世界を自由に掘り、積み、探検できる、シングルプレイ向けのボクセル(立方体ブロック)サンドボックスゲーム。
- **ジャンル**: サンドボックス / サバイバル探索
- **プレイ人数**: シングルプレイ専用(マルチプレイは対象外)
- **プラットフォーム**: ブラウザ(HTML5)。専用アプリのインストールは不要で、Webブラウザを起動するだけで遊べる。
- **ゲームの目的・ゴール**: 決められたクリア条件は存在しない。プレイヤーは地形を掘り進めたり、ブロックを組み合わせて建築したりしながら、自分なりの目標(拠点づくり、探索、収集など)を自由に設定して楽しむ、自由度の高いサンドボックス型の体験を提供する。

## 第2章:操作方法(コントロール)

プレイヤーはキーボードとマウスを使ってキャラクターを操作する。

| 操作内容 | 割り当て |
|---|---|
| 前後左右への移動 | W / A / S / D キー |
| 視点操作(見渡す方向を変える) | マウスの移動 |
| ジャンプ | Space キー |
| しゃがみ | Shift キー |
| ブロックを壊す | マウス左クリック(長押し) |
| ブロックを置く | マウス右クリック |
| インベントリの開閉 | E キー |
| ホットバーのスロット選択 | 数字キー(1〜9)またはマウスホイール |

## 第3章:ワールドとブロック

- **ワールド生成の体験**: ワールドは「シード値」と呼ばれる値をもとに自動生成される。同じシード値からは何度でも同じ地形を再現できる。地表には草原・砂浜・水辺などの起伏があり、地中には石や資源となるブロックが層状に広がっている(生成の仕組み自体の詳細は技術設計書に譲り、本書ではプレイヤーが目にする体験のみを扱う)。
- **昼夜のサイクル**: 時間の経過とともに空の明るさが昼から夜へ、また夜から昼へと段階的に変化する。1日の長さはおおむね現実時間で20分程度とする(対象範囲内で仕様が未定だったため、Minecraft Java Editionの標準値を採用)。

### ブロックの種類一覧

| ブロック名 | 入手方法 | 用途 |
|---|---|---|
| 土 | 素手または任意の道具で破壊すると入手 | 地形の材料、建材 |
| 草(草ブロック) | 破壊すると土として入手 | 地表を覆う見た目の変化、装飾 |
| 石 | ツルハシで破壊すると丸石として入手 | 丸石やその他のブロックの材料 |
| 丸石 | 石をツルハシで破壊すると入手 | 建材、道具や作業台の材料 |
| 原木 | 素手または任意の道具で木を破壊すると入手 | 木材の材料 |
| 木材 | 原木を加工(クラフト)すると入手 | 建材、道具・作業台の材料 |
| 葉 | 木を破壊すると低確率で入手 | 装飾、景観の一部 |
| 水 | 入手不可(設置済みのものを利用するのみ) | 景観を作る環境ブロック |
| 砂 | 素手または任意の道具で破壊すると入手 | 建材、装飾 |

(上記は対象範囲を代表する例であり、対象範囲内で他に必要となるブロックが未定の場合はMinecraft Java Editionの標準的なブロック構成を採用し、その旨を注記する。)

- **ブロックの破壊時間・道具の概念(MVP簡略化ルール)**:
  - 土・砂・木材・葉などの柔らかいブロックは、道具がなくても0.5秒の長押しで破壊・入手できる。
  - 石は木のツルハシを持っている場合のみ、1秒の長押しで破壊して丸石として入手できる。ツルハシを持っていない場合は破壊できない。
  - MVPでは道具の耐久値を扱わない。木のツルハシは使用しても壊れず、破壊できるブロックの種類と破壊時間は変化しない。
  - 水は流れず、採取・設置・水中移動はできない。水に接触しても体力や移動速度は変化しない。

## 第4章:インベントリとクラフティング

- **インベントリとホットバーの仕様**: インベントリは合計36スロット(メインインベントリ27スロット + ホットバー9スロット)で構成する(対象範囲内で仕様が未定だったため、Minecraft Java Editionの標準値を採用)。ホットバーは画面下部に常時表示され、数字キーやマウスホイールで即座に持ち替えられる。
- **クラフティングの基本ルール**: プレイヤーは所持しているブロックやアイテムを組み合わせて新しいアイテムを作成できる。インベントリ画面には2×2マスの簡易クラフティング欄があり、「作業台」ブロックを設置して使用すると3×3マスのより広いクラフティング欄を利用できる(対象範囲内で仕様が未定だったため、Minecraft Java Editionの標準値を採用)。

### クラフトレシピの例

| 完成アイテム | 必要な素材 | 使用するクラフティング欄 |
|---|---|---|
| 木材 ×4 | 原木 ×1 | 2×2(簡易) |
| 棒 ×4 | 木材 ×2 | 2×2(簡易) |
| 作業台 ×1 | 木材 ×4 | 2×2(簡易) |
| 木のツルハシ ×1 | 木材 ×3 + 棒 ×2 | 3×3(作業台) |

- **アイテムスタックの概念**: 同じ種類のアイテムは1つのスロットにまとめて持てる。ブロック類は最大64個まで、木のツルハシなどの道具類は1スロットに1個のみ持てる(対象範囲内で仕様が未定だったため、Minecraft Java Editionの標準値を採用)。

## 第5章:プレイヤーの状態とサバイバル要素

- **移動・ジャンプ・重力の体感仕様**: プレイヤーは徒歩相当の速度で移動し、Spaceキーでその場から軽く飛び上がる程度の高さまでジャンプできる。ジャンプ後は重力によって自然に落下し、着地するまで空中で緩やかに滞空する感覚を再現する(数値は概略でよい)。
- **サバイバル要素の対象範囲**: 体力システムはMVP対象とする。体力は最大10ポイントで、画面上に常時表示する。4ブロック以上の高さから落下すると、4ブロック目から1ブロック増すごとに1ポイントの落下ダメージを受ける。空腹値・敵対Mobは本MVPの対象外とし、これらに起因する体力減少やスタミナ管理は行わない。
- **回復・死亡・復活**: ダメージを受けてから10秒間、追加ダメージを受けなければ、以後10秒ごとに体力を1ポイント自然回復する。体力が0になると、プレイヤーはワールド作成時に決められた初期スポーン地点で体力10ポイントの状態で復活する。死亡してもインベントリ、選択中のホットバー、設置・破壊したブロックは失われない。ベッドなどによるスポーン地点の変更はMVP対象外とする。

## 第6章:セーブ&ロード

- ワールドは30秒ごとに自動保存され、ワールド選択画面へ戻るときにも保存される。保存中は、変更したブロックとプレイヤーの状態を同じ時点の内容として保存する。
- プレイヤーの状態として、位置、視点の向き、インベントリの内容、選択中のホットバー、体力、初期スポーン地点を保存する。再開時は、これらの状態と変更済みの地形を復元する。
- プレイヤーは複数のワールドを作成・管理できる。各ワールドは名前、シード値、地形の変更内容、プレイヤーの状態を個別に保持し、タイトル画面のワールド選択リストから続きを再開したいワールドを選べる。別のワールドを選ぶ前には、現在のワールドの保存を完了する。

## 第7章:対象外機能(既知の制約)

以下の要素は、本仕様書が扱うMVPフェーズの対象外とする。将来のバージョンにおける拡張候補として位置づける。

- マルチプレイ
- レッドストーン回路
- エンチャント
- ネザー/エンドなどの異次元
- 村人との取引
- 天候システム
- 空腹値システム
- 敵対Mob
- 農業・作物の栽培
- 水流、水の採取・設置、水中移動
- 道具の耐久値
- ベッドなどによるスポーン地点の変更
